## Project name and elevator pitch

Deadlock Manor

A haunted incident-response game where evidence, action budgets and causal replay turn debugging decisions into a playable mystery.

## Inspiration

Incident dashboards show symptoms; learning often requires understanding which intervention changed the outcome. Deadlock Manor makes the investigation tangible: enter a failing system, inspect evidence, spend a limited action budget and compare an alternative branch against the original decisions.

## What it does

Three fictional incident scenarios model resource exhaustion, a retry cascade and a bad rollout. Actions alter a deterministic simulation, so the player must resolve the underlying chain rather than click every remedy. A causal replay explains decisions and a counterfactual drill lets the player revisit a different course. Local save validation and downloadable reports make the run reviewable.
