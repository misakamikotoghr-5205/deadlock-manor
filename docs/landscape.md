## 选定的实际提升：因果重演实验室

原版本只能看最终分数、行动日志和总结。玩家做错一次干预后，要从头重玩才能比较另一选择；记忆中的指标与后续读到的证据还容易混在一起。本轮加入可操作的检查点重演，而不是修改主题或增加宣传文案。

1. 结案后选择某个**实际行动前**的检查点。`replay.js` 使用相同引擎从原事件历史重建状态，保留当时的预算、系统状态、指标与已读证据；不会把未来才读到的证据带回去。
2. 选择当时合法的另一干预。界面并排展示原行动和替代行动**各推进一回合后**的四项指标、剩余预算、行动解释及 Commander 建议。
3. 差值严格定义为“替代行动结果 − 原行动结果”。包含引擎的环境推进，明确提示这是一回合规则模拟，不是线上系统预测，也不是完整恢复路径的优劣排名。
4. 预览不修改原案卷；可导出比较 JSON。明确选择继续分支后，替代状态才成为当前班次；原案卷保存在本机，并提供返回原案卷按钮。新开一局会清除这份分支备份。存储不可用时，原案卷仍保留在当前标签页内。

改动文件：`replay.js`、`app.js`、`index.html`、`styles.css`、静态构建/语法检查脚本和 `tests/replay.test.js`。现有三角色建议仍是规则驱动，不声称用了 LLM 或真正的多智能体推理。

## 验证与边界

`npm test` 新增四项行为测试：三个场景的检查点均只带入当时证据；替代路径状态通过正式引擎的历史重放校验；比较差值与两条真实状态一致；原案卷完全未变；并拒绝伪造历史、越界检查点和当时不可用的行动。`npm run check` 和 `npm run build` 包含新模块，产物仍无运行时依赖或网络调用。

这让本作品的复盘更可练习，但没有补齐真实日志接入、多人指挥、未知场景泛化、真实基础设施压测或专业培训验证。浏览器最终交互、窄屏表格及导出由主智能体统一 QA；单元测试不代替用户研究。
